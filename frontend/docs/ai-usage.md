# Использование ИИ-ассистента

По запросу участника команды Codex прочитал условия кейса, подготовил исходники фронтенда, API-контракт, документацию и тест демосценария. Человек определил задачу фронта, ограничение «бэкенда пока нет», потребовал разделить монорепозиторий по папкам и запросил публикацию. Состав и реализация остальных частей команды здесь не описываются.

Код проверялся `node --test`, синтаксической проверкой Node и в браузере на ширинах 320, 360, 390, 768 и 1024 px. При проверке нашли переполнение таблицы сотрудников на узком экране и карточки рабочего на планшете; CSS исправили и повторили проверку. После повторного просмотра сценария добавили опрос статуса смены на телефоне, чтобы вход с другого устройства отражался без перезагрузки. Эти проверки относятся к фронту и демо; серверную безопасность они не подтверждают.

Помощник проекта не вызывал модель для ответов руководителю: такого серверного слоя пока нет. Подключать реальную модель и проверять её ответы должна команда после появления бэкенда.

В текущей правке ассистент добавил согласование DOM без зависимостей, OIDC, ECDSA-адаптер и регрессионные проверки. Браузерный тест выполнялся против mock API; он не подтверждает настоящий backend. Точный wire format 01–08 отсутствовал, поэтому device-v1 явно отключён до согласования.
