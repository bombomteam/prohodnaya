# Текущее состояние после исправлений фронта

Реализованы: согласование DOM существующих шаблонов, роли и раздельные меню, PKCE через предложенные серверные auth-endpoints, refresh/login/logout, Bearer-транспорт, отдельный справочник людей для отчётов, read-only план руководителя, UI enroll-кода/отзыва/деактивации, WebCrypto/IndexedDB адаптер device-v1, таймауты, защита от повторного запуска busy, сохранение ввода и камеры, сброс фото, загрузка схемы и динамическое число зон. Деморежим явно помечен; административные операции, которых нет в демо, сообщают о необходимости backend.

Проверены: три Node-теста, сборка, роли и mobile layout в Edge, сохранение формы/сброс FileList, криптографическая регистрация и чтение своего профиля после reload против проверяющего mock API. Реальный Keycloak, backend, камера, Docker и мобильный фон не проверены.

Не закрыто: настоящие серверные проверки, сохранение в PostgreSQL, реальные провайдеры модели, совместимость device-v1 с 01–08 (файлы отсутствуют), окончательный формат плана/калибровки, восстановление финального решения по API после потери ответа. device-v1 выключен по умолчанию до согласования. Стенд остаётся прототипом, а не готовым допуском по кейсу.

Экраны описаны HTML-шаблонами; view.js согласует DOM без зависимостей. Неизвлекаемый ключ не защищает от исполнения вредоносного кода того же origin. Изменение домена туннеля требует повторной привязки.
