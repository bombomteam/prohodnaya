# Запуск фронтенда

## Что запускается

Сейчас это статическое браузерное приложение без пакетов npm. Оно показывает четыре роли: администратора, контролёра, рабочего и руководителя. В `config.js` включён `mode: "demo"`: примеры и состояние хранятся в `localStorage` конкретного браузера. Каждый браузер видит собственный набор демоданных.

## Локально

Требуется Python 3 и современный браузер. Из корня репозитория:

```powershell
cd frontend
python -m http.server 8080
```

Откройте `http://localhost:8080`. Через `file://` запускать нельзя: браузер блокирует ES-модули и функции устройств. На первом экране появится «Обстановка» и предупреждение «Демонстрационный режим». Учётные данные в деморежиме не нужны. Кнопки ролей находятся в левом меню на компьютере и в нижней панели/меню «Ещё» на телефоне.

Для проверки кода нужен Node.js 22 или новее:

```powershell
cd frontend
npm test
npm run build:pages
```

Сборка создаёт `frontend/dist/pages/` только с HTML, CSS и JS для GitHub Pages. Папка `dist/` игнорируется Git.

## Подключение сервера

Установите в `frontend/config.js` `mode: "api"` и адрес `apiBaseUrl`. Сервер должен поддерживать маршруты и формы ответов из [frontend-api.md](frontend-api.md). Все HTTP-запросы находятся в `frontend/src/api.js`, поэтому несовпадающие поля можно нормализовать в одном месте.

Сервер сам отвечает за вход пользователя, права ролей, постоянное хранение, проверку лица, WebAuthn, смены, аналитику и помощника. Интерфейс не содержит тестовых учётных данных для реального режима. Если фронт и API размещены на разных доменах, настройте CORS для точного origin и передачу cookie. Для WebAuthn, камеры и геолокации на удалённом телефоне нужен HTTPS; `localhost` подходит для локальной разработки.

После подключения прогоните полный путь на новом сотруднике: загрузка эталона → привязка телефона → вход и выход с камерой → координаты только в открытой смене → журнал и отчёты. Отдельно проверьте чужое лицо, повтор одного подтверждения, фото без лица/с несколькими людьми и отказ внешних сервисов. Пока сервера нет, эти проверки выполнить нельзя.
