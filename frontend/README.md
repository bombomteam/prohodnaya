# Фронтенд «Проходной»

Статическое приложение на ES-модулях без npm-зависимостей и сборщика. Правила работы: [AGENTS.md](AGENTS.md).

Из каталога `frontend`:

```powershell
python -m http.server 8080
npm test
npm run build:pages
```

Открыть http://localhost:8080. Деморежим работает без сервера и не доказывает безопасность прохода. В API-режиме фронтенд соответствует схемам backend, слитого из `feature/svyat`; настройка и ограничения описаны в [контракте](docs/frontend-api.md). Для локальной проверки операторских экранов нужны `?devRole=admin|manager|controller` и `AUTH_DEV_BYPASS=true` на backend.

В разделе «Аналитика» показаны только Бетономешалка, Котлован и Курилка. Выбор карточки с ФИО открывает маршрут работника. Фотографии зон взяты из материалов кейса; их взаимное расположение условно до получения плана и геопривязки от backend.

См. [запуск](docs/launch.md) и [ограничения](docs/limitations.md).

Версия рабочего: `/?worker=1`, без аккаунта администратора или Keycloak.
Новый сценарий шестизначного кода готов в деморежиме; API пока использует существующую QR-подпись
до получения согласованного контракта. Подробности и сценарий проверки — [телефон и проход](docs/worker-passage.md).
